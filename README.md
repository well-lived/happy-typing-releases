# Happy Typing

Happy Typing 是一款 macOS 菜单栏应用。打字时，光标旁会长出枝叶、开出小花，也可以换成一尾游动的锦鲤。你可以单独开关键盘音效，在「我的」查看敲击统计，或在「小憩」里听一会儿雨声。

[官网下载](https://happytyping.welllived.cn/) · [版本与安装包](https://github.com/well-lived/happy-typing-releases/releases) · [隐私政策](https://happytyping.welllived.cn/policies/privacy.html)

## 安装与更新

1. 从官网下载 Mac 版。使用 GitHub 下载时，在对应版本的 Assets 中选择以 `-universal.dmg` 结尾的文件。
2. 打开 DMG，将 Happy Typing 拖入「应用程序」，启动后按引导开启需要的功能。支持 macOS 14 及以上，通用安装包兼容 Apple Silicon 和 Intel Mac；部分窗口兼容功能需要 macOS 15.2 或以上。
3. 已安装的用户可在 Happy Typing 的「关于 → 检查更新」查看新版。
